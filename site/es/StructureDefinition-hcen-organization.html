Perfil de los recursos: Perfil Organización para HCEN

URL oficial: http://fhir.hcen.gub.uy/StructureDefinition/hcen-organization Versión: 0.2.0
Draft a partir de 2026-10-28 . Nombre computable: HCENOrganization

Una agrupación de personas u organizaciones con un propósito común.

Usos:

  • Utilizar este perfil: Envío para publicación documental HCEN
  • Referencia a este perfil: Por Orden De, Organización Financiadora, Identificador Cédula de Identidad, Perfil Document Reference HCEN... Show 5 more, HCEN Evento Clínico, Identificador MRN para HCEN, Identificador de Organización para HCEN, Perfil Rol del Profesional de Salud para HCEN and HCEN Consulta No Urgente
  • Ejemplos de este perfil: Administración de los Servicios de Salud del Estado
