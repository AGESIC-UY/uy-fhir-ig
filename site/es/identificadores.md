# Identificadores y datos comunes - Guía de Implementación FHIR de Uruguay v0.1.0

## Identificadores y datos comunes

Los tipos de datos comunes definen identificadores, nombres, direcciones y contactos reutilizables por los perfiles nacionales.

### Catálogo inicial

| | |
| :--- | :--- |
| [Contacto por Correo Electrónico (Uruguay)](StructureDefinition-uy-email-contact-point.md) | Detalles de contacto por correo electrónico de una persona u organización. |
| [Contacto Telefónico (Uruguay)](StructureDefinition-uy-phone-contact-point.md) | Detalles de contacto telefónico de una persona u organización. |
| [Dirección (Uruguay)](StructureDefinition-uy-address.md) | Dirección física o postal de una persona u organización en Uruguay. |
| [Cédula de identidad (Uruguay)](StructureDefinition-uy-ci-identifier.md) | Identificador nacional de una persona en Uruguay. |
| [Identificador nacional extranjero (para Uruguay)](StructureDefinition-uy-fni-identifier.md) | Identificador nacional emitido por otro país. |
| [Identificador de organización (Uruguay)](StructureDefinition-uy-aa-identifier.md) | Identificador numérico o alfanumérico único asignado de forma oficial o local a una organización. |
| [Identificador de paciente (Uruguay)](StructureDefinition-uy-mrn-identifier.md) | Identificador interno del paciente en la institución (Medical Record Number). |
| [Pasaporte (para Uruguay)](StructureDefinition-uy-ppn-identifier.md) | Identificador de pasaporte de una persona. |
| [Nombre de Persona (Uruguay)](StructureDefinition-uy-human-name.md) | Nombre de una persona optimizado para su visualización y almacenamiento estructurado, con los apellidos discriminados mediante extensiones. |

Cada página presenta el propósito del artefacto y su definición técnica. Los artefactos se incorporan como base de trabajo en estado de borrador.
