Extensión: ID Único del Repositorio

URL oficial: http://fhir.hcen.gub.uy/StructureDefinition/ext-repository-id Versión: 0.1.0
Draft a partir de 2026-10-06 . Nombre computable: RepositoryId

Identificador único del repositorio. Mapea a DocumentEntry.repositoryUniqueId de XDS.

Context of Use

    This extension may be used on the following element(s)

    • Element ID: DocumentReference
