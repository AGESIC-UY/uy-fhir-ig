# Ejemplos del Core - Guía de Implementación FHIR de Uruguay v0.2.0

## Ejemplos del Core

Esta página reúne siete ejemplos de recursos FHIR basados en los cuatro perfiles nacionales, todos utilizan datos ficticios.

## Ejemplos básicos

Los siguientes ejemplos muestran cómo representar un paciente, un profesional de salud, una organización y un rol profesional utilizando los perfiles nacionales.

| | |
| :--- | :--- |
| [Paciente](Patient-uy-paciente-perez.md) | [UYPatient](StructureDefinition-uy-patient.md) |
| [Profesional de salud](Practitioner-uy-profesional-sanchez.md) | [UYPractitioner](StructureDefinition-uy-practitioner.md) |
| [Organización](Organization-uy-organizacion-abc.md) | [UYOrganization](StructureDefinition-uy-organization.md) |
| [Rol profesional](PractitionerRole-uy-rol-medicina-general-sanchez-abc.md) | [UYPractitionerRole](StructureDefinition-uy-practitioner-role.md) |

El ejemplo de rol profesional hace referencia al profesional y a la organización incluidos en esta tabla.

## Ejemplos completos

Estos ejemplos incluyen información adicional para mostrar otras posibilidades de uso de los perfiles. Los campos opcionales que aparecen en ellos no son obligatorios.

| | |
| :--- | :--- |
| [Paciente con datos adicionales](Patient-uy-paciente-perez-completo.md) | [UYPatient](StructureDefinition-uy-patient.md) |
| [Profesional con datos adicionales](Practitioner-uy-profesional-sanchez-completo.md) | [UYPractitioner](StructureDefinition-uy-practitioner.md) |
| [Organización con datos adicionales](Organization-uy-organizacion-abc-completa.md) | [UYOrganization](StructureDefinition-uy-organization.md) |

Cada ejemplo completo representa una instancia independiente del ejemplo básico correspondiente y utiliza un identificador de recurso diferente.

## Cómo consultar los ejemplos

Cada ejemplo puede consultarse en formato JSON o XML. Estas representaciones permiten revisar todos los elementos del recurso y comprobar su conformidad con el perfil correspondiente.

Para consultar ejemplos relacionados con el intercambio y la publicación de documentos clínicos, acceder a [Ejemplos de intercambio HCEN](hcen-ejemplos.md).
