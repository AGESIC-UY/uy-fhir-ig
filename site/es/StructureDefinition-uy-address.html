Perfil del tipo de datos: Dirección (Uruguay)

URL oficial: http://fhir.hcen.gub.uy/StructureDefinition/uy-address Versión: 0.1.0
Draft a partir de 2026-10-06 . Nombre computable: UYAddress

Dirección física o postal de una persona u organización en Uruguay.

Usages:

  • Use this DataType Profile: Perfil Organización para Uruguay, Perfil Paciente para Uruguay and Perfil Profesional de Salud para Uruguay

You can also check for usages in the FHIR IG Statistics

id 0..1 string ID único del elemento dentro del recurso.

Slice: Unordered, Open by value:url
use ?!Σ 0..1 code Propósito de la dirección: home | work | temp | old | billing.
Binding: AddressUse (required): Propósito de uso de la dirección.
Example General: home
type Σ 0..1 code Dirección física (para visitas), postal (para correo), ambas.
Binding: AddressType (required): Tipo de dirección: física, postal o ambas.
Example General: both
text Σ 0..1 string Especifica la dirección completa tal como debe ser mostrada.
Example General: 137 Nowhere Street, Erewhon 9132
line Σ 0..* string El nombre de la calle junto a número de puerta, apartamento, o piso.
This repeating element order: The order in which lines should appear in an address label
Example General: 137 Nowhere Street
city Σ 0..1 string Nombre de la ciudad, pueblo, localidad.
Binding: Localidades de Uruguay (extensible): Localidades de Uruguay según el catálogo público de OSE.
Example General: Erewhon
district Σ 0..1 string Nombre del barrio o comuna.
Binding: Barrios y localidades postales de Uruguay (extensible): Barrios y localidades de Uruguay según el listado de códigos postales del Correo Uruguayo.
Example General: Madison
state Σ 0..1 string Nombre del departamento.
Binding: Departamentos de Uruguay (required): Los 19 departamentos de Uruguay.
postalCode Σ 0..1 string Código postal que define el área o zona de entrega postal.
Binding: Códigos postales de Uruguay (required): Códigos postales publicados por el Correo Uruguayo.
Example General: 9132
country Σ 1..1 string País de la dirección.
Fixed Value: URY
period Σ 0..1 Period Periodo de validez de la dirección.
Example General: {"start":"2010-03-23","end":"2010-07-01"}
