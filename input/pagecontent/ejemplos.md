Esta página reúne siete ejemplos de recursos FHIR basados en los cuatro perfiles nacionales, todos utilizan datos ficticios.

## Ejemplos básicos

Los siguientes ejemplos muestran cómo representar un paciente, un profesional de salud, una organización y un rol profesional utilizando los perfiles nacionales.

| Ejemplo | Perfil de referencia |
| --- | --- |
| [Paciente](Patient-uy-paciente-perez.html) | [UYPatient](StructureDefinition-uy-patient.html) |
| [Profesional de salud](Practitioner-uy-profesional-sanchez.html) | [UYPractitioner](StructureDefinition-uy-practitioner.html) |
| [Organización](Organization-uy-organizacion-abc.html) | [UYOrganization](StructureDefinition-uy-organization.html) |
| [Rol profesional](PractitionerRole-uy-rol-medicina-general-sanchez-abc.html) | [UYPractitionerRole](StructureDefinition-uy-practitioner-role.html) |

El ejemplo de rol profesional hace referencia al profesional y a la organización incluidos en esta tabla.

## Ejemplos completos

Estos ejemplos incluyen información adicional para mostrar otras posibilidades de uso de los perfiles. Los campos opcionales que aparecen en ellos no son obligatorios.

| Ejemplo | Perfil de referencia |
| --- | --- |
| [Paciente con datos adicionales](Patient-uy-paciente-perez-completo.html) | [UYPatient](StructureDefinition-uy-patient.html) |
| [Profesional con datos adicionales](Practitioner-uy-profesional-sanchez-completo.html) | [UYPractitioner](StructureDefinition-uy-practitioner.html) |
| [Organización con datos adicionales](Organization-uy-organizacion-abc-completa.html) | [UYOrganization](StructureDefinition-uy-organization.html) |

Cada ejemplo completo representa una instancia independiente del ejemplo básico correspondiente y utiliza un identificador de recurso diferente.

## Cómo consultar los ejemplos

Cada ejemplo puede consultarse en formato JSON o XML. Estas representaciones permiten revisar todos los elementos del recurso y comprobar su conformidad con el perfil correspondiente.

Para consultar ejemplos relacionados con el intercambio y la publicación de documentos clínicos, acceder a [Ejemplos de intercambio HCEN](hcen-ejemplos.html).
