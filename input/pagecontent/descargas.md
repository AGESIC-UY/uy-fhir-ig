El [paquete FHIR de esta compilación](../package.tgz) contiene los recursos de la guía y se genera con IG Publisher.

| Propiedad | Valor |
| --- | --- |
| Guía | Guía de Implementación FHIR de Uruguay |
| Identificador | `uy-fhir-ig` |
| Paquete | `fhir.uy` (identificador de trabajo pendiente de confirmación institucional) |
| URL canónica base | `http://fhir.hcen.gub.uy` |
| Versión | `0.1.0` |
| FHIR | R4 (`4.0.1`) |
| Estado | Borrador en desarrollo |

El paquete se genera a partir de los recursos del Core y de la primera versión HCEN. Consultar los catálogos de [perfiles HCEN](hcen-perfiles.html), [extensiones](hcen-extensiones.html), [terminología](hcen-terminologia.html) y [ejemplos](hcen-ejemplos.html). Las fuentes HCEN requieren compilación y validación; una descarga de una compilación anterior puede no incluirlas. La validación terminológica y la revisión nacional están pendientes.

Consultar el [historial de cambios](cambios.html).
